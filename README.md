# Exploratory-data-analysis-EDA-using-python
Exploratory Data Analysis (EDA) project built using Python on a generated Superstore dataset. Analyzed sales, profit, orders, customer segments, regions, categories, and business performance using Pandas, NumPy, Matplotlib, and Seaborn


# Superstore Sales Data Analysis (EDA)

## Project Overview

This project focuses on **Exploratory Data Analysis (EDA)** using a randomly generated Superstore dataset created in CSV format (`superstore_data.csv`). The objective is to analyze sales performance, profitability, customer behavior, product trends, and regional performance using Python data analysis and visualization libraries.

The project demonstrates basic, intermediate, and advanced data analysis techniques commonly used in Data Analytics and Business Intelligence.
